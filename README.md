# 海大活動報名系統 (NTOU Event Registration System)

## 專案簡介
本專案為期末專案，旨在開發一個專為國立臺灣海洋大學設計的活動報名系統。

## 基本需求 (MVP)
1. 使用者分為訪客、一般使用者、活動管理者與系統管理員。
2. 所有使用者可搜尋與查看活動資訊。
3. 註冊使用者可報名參加活動。
4. 使用者可查看已報名活動與參與過的活動歷史。
5. 一般使用者分為學生、教師與行政人員。
6. 系統管理員可設定活動管理者權限。
7. 活動管理者與系統管理員可建立活動與查看名單。
8. 系統應提供基本的活動報名確認與取消機制。

## 進階需求
1. 進階使用者修改活動資訊（如時間）時，自動通知已報名者。
2. 活動結束後系統會記錄實際參與情況，並可讓進階使用者查詢。
3. 支援報名上限與候補名單功能。
4. 整合Google Calendar，同步活動行程。
5. 整合Google Map，顯示所有活動地點。
