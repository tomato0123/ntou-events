# 海大活動報名系統 (NTOU Event Registration System)

## 專案簡介
本專案為期末專案，旨在開發一個專為國立臺灣海洋大學設計的活動報名系統。

## 基本需求 (MVP)
1. 使用者分為訪客、一般使用者、活動管理者與系統管理員。
2. 所有使用者可搜尋與查看活動資訊。
3. 註冊使用者可報名參加活動。
4. 使用者可查看已報名活動與參與過的活動歷史。
5. 一般使用者分為學生、教師與行政人員。
6. 系統管理員可設定活動管理者權限。
7. 活動管理者與系統管理員可建立活動與查看名單。
8. 系統應提供基本的活動報名確認與取消機制。

## 進階需求
1. 進階使用者修改活動資訊（如時間）時，自動通知已報名者。
2. 活動結束後系統會記錄實際參與情況，並可讓進階使用者查詢。
3. 支援報名上限與候補名單功能。
4. 整合Google Calendar，同步活動行程。
5. 整合Google Map，顯示所有活動地點。

## 主頁原型

直接以瀏覽器開啟 `index.html`，不需要安裝套件或建置。

- `index.html`：主頁結構與活動詳情視窗。
- `styles.css`：桌面、平板與手機版樣式。
- `app.js`：示範活動、搜尋、分類篩選、載入更多與詳情互動。

目前提供 8 筆虛構活動，非正式校園公告；尚未串接資料庫、登入、報名或建立活動功能。活動列表預設隱藏已結束活動，並依發佈時間由新到舊排序。示範活動日期為 2026 年 11 月，日期過後可更新 `app.js` 中的資料以繼續展示。

搜尋支援名稱、簡介、地點及主辦單位，可與分類一起使用。在一般 HTTP 網址下，搜尋與分類會保存於網址參數，便於重新整理及分享；直接開啟本機檔案時，網址保存是否可用依瀏覽器限制而定。
