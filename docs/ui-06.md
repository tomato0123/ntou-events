MVP 僅查閱正式報名及取消紀錄，不提供候補或出席登記，也不把已報名視為已出席。選單包含目前角色可管理的活動，不依賴公開活動列表，亦不以活動公開狀態限制有權管理者查閱。

## 頁面與啟動

- 首頁新增「活動管理」入口，開啟 `manager.html`。
- 後端啟動後可直接開啟 `http://127.0.0.1:8000/manager.html`（自訂 PORT 時使用該埠）。後端僅提供列出的前端檔案，不把專案目錄、憑證、測試程式或資料庫腳本公開成靜態資源。
- 後端提供的 `api-config.js` 固定使用同源 `/api`；其他本機靜態伺服器使用檔案中的設定，預設連線 `http://127.0.0.1:8000/api`。正式部署優先使用同源，不使用網址參數指定 API 主機。
- 初次載入自動選擇第一個可管理活動；重新整理保留仍有權限的選項，否則選擇第一個。時間統一顯示 Asia/Taipei。
- 狀態篩選提供全部／已報名／已取消。顯示篩選後的「名單筆數」，全部／已報名篩選另顯示有效報名的不同使用者人數；取消後重報的歷史紀錄不誤稱為不同人數。
- 表格顯示報名編號、姓名、Email、校園身分、性別、報名狀態、報名時間；選填空值顯示「未提供」。手機版僅表格區域可橫向捲動，頁面本身不橫向溢出。
- 未登入、無管理權限、無可管理活動、活動空名單、篩選無紀錄、活動消失與網路／伺服器失敗分開提示；失敗可重試，不當成零筆。
- 變更活動、篩選、帳號及登出時立即清空舊名單；取消過時請求，舊回應不得覆寫新狀態。背景分頁清空名單，返回重新查核。API 回應不快取，前端不持久化名單。
- 所有活動及報名資料用 textContent／Option 顯示，不插入為 HTML。

## US-02 登入串接契約

`auth-session.js` 提供 `window.NtouSession`：

```js
// 只有正式登入成功後才呼叫，token 為 API 回應的 Bearer Token。
NtouSession.setToken(loginResponse.token);
// 同一個來源、同一分頁跳轉後，manager.html 可讀取登入狀態。
location.assign('manager.html');
// 登出：
NtouSession.clear();
```

- Token 使用 sessionStorage 的 `ntou.auth.token`；不存密碼、不存角色、不把 Token 放在 URL。UI 不解碼 JWT 作為授權依據，管理活動與名單 API 均向資料庫查核目前角色。
- `getToken()` 供 UI 取得 Token，`setToken()`／`clear()` 會發出 `ntou:session-change`，立即清除舊資料並重新載入。US-02 應使用此介面，不直接寫 storage 後期待同頁自行刷新。
- 401 清除失效 Token 並提示重新登入；403 保留登入狀態但清空名單。尚無正式登入頁時不加入無效連結或 Token 輸入框。
- 若 US-02 改採 HttpOnly cookie，應一起更新此介面與 requestJson 的認證方式，不在 UI-06 私自更換後端身分驗證協定。
- 現有 `/api/auth/login` 仍是原型，不能將本頁測試成功等同於正式帳密身分驗證完成。

## 新增 API：GET /api/manage/events

此端點經使用者確認，用於 UI-06 活動選單；名單仍使用既有 `GET /api/events/{id}/registrations`。

- 需要 `Authorization: Bearer <token>`。
- 每次依 Token 的 ID 查詢 users 目前角色；未登入／帳號不存在為 401，一般使用者或已撤權為 403。
- admin 可取得全部活動，包括 manager_id 為 NULL；event_manager 只取得 manager_id 等於自己 ID 的活動。SQL 在後端套用條件，不先回傳全部活動給前端過濾。
- 不接受使用者指定 role／manager_id 來改變範圍。不需要新增資料庫欄位或遷移。
- 成功為 200，依 starts_at ASC、id ASC 排序。無可管理活動回傳 `{ "data": [] }`。
- 回應欄位限 id、title、location、starts_at、ends_at，不包含報名資料或使用者個資。
- 500 使用一般中文錯誤，不回傳資料庫內部訊息；所有結果包含 Cache-Control: no-store。

```json
{
  "data": [{
    "id": 101,
    "title": "海洋永續講座",
    "location": "電資大樓 302",
    "starts_at": "2030-01-01T01:00:00.000Z",
    "ends_at": "2030-01-01T04:00:00.000Z"
  }]
}
```
